# Projet M1 – Keylogger Python

## Présentation

Dans le cadre de mon Master 1, j'ai réalisé un keylogger en Python pour mieux comprendre son fonctionnement et les risques qu'il représente en cybersécurité.

Le programme permet de :
- Enregistrer les touches tapées au clavier.
- Se faire passer pour une image afin de masquer son exécutable.
- Envoyer les touches enregistrées par e-mail.

## Technologies utilisées
- Python
- Pynput
- SMTP
- PyInstaller

## Objectif

Ce projet m'a permis de découvrir comment fonctionne un keylogger, notamment la récupération des frappes clavier et les techniques de dissimulation.

**Ce projet a été réalisé uniquement à des fins pédagogiques, dans un environnement de test autorisé.**
